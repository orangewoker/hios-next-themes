# 夏日玻璃

HIOS Next 内置双模式主题，ID `hios.summer-glass`。

- 浅色：薄荷绿光场、乳白玻璃、深绿色文字与操作。
- 深色：森林绿背景、墨绿玻璃、清晰的薄荷绿操作。
- 在设置的“主题与外观”中选择；侧栏底部与画布左下角继续切换深浅色。
- 默认主题始终在第一位；夏日玻璃随应用更新，不改动用户已选主题。
- 公共控件、节点外壳和 Portal 菜单通过语义变量适配。插件通过原有主题消息接收颜色；未接入主题协议的第三方内容不会被强制改写。
- 图片、视频、色板、绘图内容及页面背景不染色。重复节点不启用 backdrop blur。
- 两个模式共用 `theme.css`，由根元素 `data-theme` 选择完整调色板。

主题需要支持 `schemaVersion: 2` 的 HIOS；无需网络请求或第三方 JavaScript。
